## 🚀 About Acode Next

**Acode Next** (maintained by [**@ssfuisu**](https://github.com/ssfuisu)) is a supercharged, high-performance fork of the popular Acode code editor for Android.

Unlike standard mobile editors, **Acode Next** integrates a full **Ubuntu 24.04 LTS (Noble Numbat)** glibc Linux environment running directly in user space via optimized PRoot, accompanied by in-app GitHub integration and a native Downloads manager.

### ✨ Key Advantages over Original Acode

| Feature | Upstream Acode | Acode Next (by ssfuisu) |
| :--- | :---: | :---: |
| **Linux Environment** | Limited / Alpine musl | **Pure Ubuntu 24.04 LTS (glibc)** |
| **Python & Binary Wheels** | ❌ Fails on compiled wheels | ✅ **Full pip / numpy / torch / wheel support** |
| **Rootfs Extraction** | ❌ Hardlink errors on Android | ✅ **PRoot `--link2symlink` automated fix** |
| **In-App GitHub** | ❌ Redirects to external browser | ✅ **Built-in Session Browser + Close button** |
| **Downloads Manager** | ❌ Not available | ✅ **Dedicated Downloads sidebar app + 1-tap APK install** |
| **Acode CLI Integration** | ⚠️ Partial | ✅ **`acode <path>` fast terminal bridge** |
| **Automated CI/CD** | Manual / slow releases | ✅ **Continuous build on every commit** |

## 📥 Download & Installation

1. Download the latest single-file APK from our official site or GitHub:
   - **Official Website:** [https://ssfuisu.github.io/Acode/](https://ssfuisu.github.io/Acode/)
   - **Direct APK Download:** [Acode-Ubuntu24-Release.apk](https://github.com/ssfuisu/Acode/releases/download/latest-release/Acode-Ubuntu24-Release.apk)
2. Install the APK on your Android device and grant storage permissions.
3. Open Acode Next, open the **Terminal** tab, and install Ubuntu 24.04 LTS with one tap.
4. Enjoy desktop-grade programming in Python, Node.js, C/C++, Rust, Go, and more!
